# Android 0.7.21.17：收藏夹封面与歌词匹配

- 收藏夹改用有封面的分页列表 `/x/v3/fav/folder/created/list`；打开已有收藏夹时读取 `/x/v3/fav/folder/info` 更新封面和计数。仍只读取当前登录账户自己的收藏夹。
- Android 图片缓存经原生请求读取 `hdslb.com`，避免 WebView 的 CORS 限制。
- 视频的歌词搜索经 Omni 获取独立的匹配信息：提取明确的歌名、歌手，移除画质/字幕等展示标签，不将 UP 主当歌手，不将视频标题当专辑。原始视频标题、封面、BV/CID 和播放源不变。
- 夜鹿、ヨルシカ、Yorushika 在歌词查询与评分中识别为同一歌手；保留歌词库的多语言歌名。空结果可再试不含专辑和分隔符的关键词。没有音乐平台候选时也直接搜索 AMLL。
- 只有歌名、歌手精确匹配时允许视频与录音总长度相差最多 30 秒；翻唱、现场、合集和无法可靠识别的标题不自动保存匹配。此容差不移动歌词时间轴，不表示已经对齐人声。
- 播放、预取、手动触发自动匹配使用同一份信息。切歌后停止后续搜索，迟到结果不更新当前歌曲界面。歌词查询不阻塞音频开始。
- 手动搜索区分服务错误与真正的空结果，允许重试或换来源。

## 边界

本版本没有声纹识曲或语音强制对齐模型，不能从任意音频识别歌曲，也不能自动纠正剪辑、变速或不同演唱版本的每句时间。现有逐曲歌词时间偏移仍可手动调节并记忆；它不是语音识别。歌词库没有收录时仍可能搜不到。

2026-10-23 匿名实测：原生桥使用的网易云 EAPI 搜索“晴る ヨルシカ”返回原曲候选，并取得该曲 58 行歌词、56 行翻译、55 行罗马音；AMLL 的“晴る”“花に亡霊”歌名查询无结果，Yorushika 查询包含《春泥棒》。这是开发环境的公开请求，不是用户收藏夹或手机端实测。
