# Android 0.7.21.22：移除手机本地识别负担

用户实测 0.7.21.21 的本地识别慢、卡顿且歌词不准确。之前的真实模型测试使用短语音，不能代表手机上整首歌曲的表现；不再把该方案默认放进导入流程。

- 导入继续自动检索、保存并显示现有歌词，缺失或标题不明确时保留未匹配状态。不会为此下载完整音频、解码或启动语音识别 Worker。
- 升级读取原队列时，把等待识别和中断的识别任务转回文字搜索，保留暂停状态、已完成任务和用户保存的歌词。不会因旧任务卡在识别状态而一直显示加载。
- Android 编译时移除本地识别入口及其动态模块；即使构建环境残留模型目录变量，也不打包 Whisper 模型。已保存机器字幕的来源标签使用独立常量，不再把识别服务引入播放器。
- 网页、桌面手动识别面板改为打开时才加载；自动导入不再使用它。手机上已有的手动校准备份仍可恢复，不需要加载识别模型。
- 设置文案同步为当前实际行为，不再宣称导入会自动识别缺失歌词。

## 验证

- 队列迁移、歌词持久化、播放竞态、命令注册与 Omni 架构共 95 项专项单测通过。
- 3 项浏览器回归通过：导入缺词视频及重启均没有音频下载、识别 Worker 或模型请求；有现成歌词时自动匹配、保存、显示，重启后不重复搜索；原有手动校准备份恢复流程保留。
- 检查 Android 产物不含语音识别 Worker、Whisper 模型和对应 ONNX 运行时资源，沿用原应用签名。

## 尚未解决

此版本消除本地识别带来的 CPU、内存和整段音频下载负担，未宣称解决全部卡顿或歌词准确率。没有现成歌词的歌曲仍可能无歌词，现有歌词也可能属于不同录音版本。可靠的自动歌声识别与人声对齐没有完成手机实测，当前不提供替代识别承诺。没有接入用户手机和私人收藏夹测试。
